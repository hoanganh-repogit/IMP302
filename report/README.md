# LaTeX report (IEEE)

- `main.tex`: the report, `IEEEtran` class (conference, A4), written in English
- `figures/`: 12 figures and charts, generated by `tools/make_report_figures.py`
- `data/`: raw numbers behind every table and chart
  - `test_per_image.csv`: per-image results on the test split (configurations A and V)
  - `real_cases.csv`: case R1–R4 of every real photo, with the statistics used to assign it
  - `real_case_metrics.json`, `synthetic_results.json`, `timing.json`, `verify_impl.txt`

## Compiling (pdfLaTeX, the Overleaf default)

**Overleaf:** you need a zip file containing `main.tex` and `figures/`. The zip is not stored in git; create it with:
```powershell
.\.venv\Scripts\python.exe tools\make_overleaf_zip.py    # -> report\IMP302m_report_overleaf.zip
```
Then choose New Project → Upload Project → select the zip → Recompile.
Do not use `Compress-Archive`: it writes paths with `\`, and Overleaf will not find the figures.

**Locally** (MiKTeX or TeX Live), run twice to resolve figure, table and reference numbers:
```
pdflatex main.tex
pdflatex main.tex
```

## Authors
- The `\author` block lists the 3 team members: Ngô Quang Huy, Nguyễn Đức Mạnh, Hoàng Văn Anh.
- Names with Vietnamese diacritics are wrapped in `\vn{...}`, which switches to the T5 font encoding (`vntex` package, included in Overleaf). The report therefore **still compiles with pdfLaTeX**.
- To add student IDs, a class or an instructor, add a line to the corresponding `\IEEEauthorblockA`, or add another `\and \IEEEauthorblockN{...}` block.

## Reproducing the numbers
```powershell
.\.venv\Scripts\python.exe tools\generate_synthetic.py
.\.venv\Scripts\python.exe tools\import_hf_coins.py
.\.venv\Scripts\python.exe tools\real_cases.py
.\.venv\Scripts\python.exe tools\experiment_real.py data\real\hf_coins dev
.\.venv\Scripts\python.exe tools\experiment_real.py data\real\hf_coins test A,C,G,N,V,X
.\.venv\Scripts\python.exe tools\make_report_figures.py
```
